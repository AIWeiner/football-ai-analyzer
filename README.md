# ⚽ AI Football Tactical Analyzer

Upload a short football clip, choose a tactical philosophy, and get back a structured post-play tactical report — generated by Google Gemini's video understanding, no manual tagging required.

**🔗 Live app:** https://football-ai-analysis.streamlit.app/

---

## What it does

Coaches and analysts often review short clips (a build-up sequence, a pressing trigger, a transition) and want quick, structured feedback rather than a full match breakdown. This app automates that first pass:

1. You upload a 15–20 second clip and tell it which team to focus on (by shirt color).
2. You select the team's tactical model — **Positional Play**, **High Press After Loss (Gegenpressing)**, **Fast Transition / Counter-Attack**, or a **custom philosophy** you describe yourself.
3. The clip is sent directly to Gemini as video input, along with a structured prompt that asks the model to act as a tactical analyst and evaluate the play against the chosen philosophy.
4. The app returns a Markdown report with three sections:
   - 🟢 **Positive Tactical Aspects** — 2–3 standout actions
   - 📊 **Key Actions & Observed Events** — passing, pressing intensity, key players
   - ⚠️ **Alignment with the Game Model & Improvement Opportunities** — deviations from the chosen philosophy, plus one concrete, actionable correction

No sign-up and no API key needed to use the live app — it runs on a shared key configured by the site owner.

## How it works

There's no custom computer-vision or tracking pipeline here — the app leans entirely on Gemini's native multimodal video understanding. The Python layer is responsible for:
- Building the sidebar UX (tactical model selection, custom rules, team color)
- Constructing a structured, role-based prompt that anchors the model's analysis to the selected tactical philosophy
- Uploading the clip to the Gemini Files API and generating the report
- Automatically falling back across a short chain of Gemini models if the primary one is temporarily overloaded (a transient `503` error on Google's side, not something within the app's control)

## Tech stack

- **Python**
- **[Streamlit](https://streamlit.io/)** — UI and app framework
- **[Google Gemini API](https://ai.google.dev/)** (`google-genai`) — video ingestion + tactical analysis generation, primarily `gemini-3.5-flash-lite` with automatic fallback to `gemini-2.5-flash-lite` / `gemini-2.5-flash`

## Getting started

### Prerequisites
- Python 3.9+
- A free [Google Gemini API key](https://aistudio.google.com/apikey) (only needed if you're running/deploying your own copy — visitors to the live app don't need one)

### Installation

```bash
git clone https://github.com/AIWeiner/football-ai-analyzer.git
cd football-ai-analyzer
pip install -r requirements.txt
```

Create a local secrets file so the app can read your API key (this file is git-ignored and never committed):

```bash
mkdir .streamlit
echo 'GEMINI_API_KEY = "your-real-key-here"' > .streamlit/secrets.toml
```

Then run it:

```bash
streamlit run app.py
```

If you deploy to Streamlit Community Cloud, add the same `GEMINI_API_KEY` in the app's **Settings → Secrets** panel instead — no code changes needed.

### Usage
1. In the sidebar, pick the team's tactical model (or write your own custom rules) and the shirt color of the team to analyze.
2. Upload a clip (MP4/MOV/AVI, ~15–20 seconds).
3. Click **🚀 Analyze Play** and the tactical report renders on the right.

## Known limitations & roadmap

- Currently tuned for short clips (~15–20 sec) rather than full-match footage.
- Analysis quality depends entirely on Gemini's video understanding for the active model — there's no dedicated tracking or event-detection layer (yet).
- The app currently runs on a single shared API key, so it's open to anyone with the link; a lightweight access gate is a natural next step if usage grows.
- Planned: To provide a set of tracking-data explanation and extent the video length limit.
